## 2. 확정 결론 (상세: `4_메일_itivai/2026-07-14_발송_첨부_보고서_stride4_학습가능성.md` §4·§5)

1. **24px까지 라벨 + 학습 때 30px 코드 필터.** 컷이 커질수록 공통 val 점수가 꾸준히 내려간다(24px −3.21%p · 30px −5.38%p · 36px −8.42%p · 48px −11.09%p). 라벨 작업량은 24px에서 이미 절반 가까이 줄어 24~30px가 알맞다. 36px 이상은 쓰지 않는다.
2. **가늘고 긴 물체 예외는 지금대로 유지**(길이 72px↑) — 없애면 rebar −41% · small pipe −34%, 두께 조건을 더해도 rebar −22%. 두께 6px 미만은 작업 우선순위 맨 뒤.
3. **mask_ratio 기본값(4) 유지** — 1은 불가, 2는 개선 없음.
4. "필터를 높일수록 좋다"(1024 자기val)는 자기 val에서만 보이는 착시다 — 공통 val에선 순서가 뒤집힌다.
5. 예외 정책끼리의 전체 점수 차이(0.34%p 이내)는 seed 차이(0.73%p) 안쪽이다. 판단은 rebar·small pipe로 한다.
